# Invitation fonts

The invitation serves these Google Fonts locally so it does not depend on a
third-party font request inside LINE's browser.

- **LXGW WenKai TC Regular** — Traditional Chinese handwriting, from
  https://github.com/google/fonts/tree/main/ofl/lxgwwenkaitc
- **Iansui Regular** — retained as a fallback for missing characters, from
  https://github.com/google/fonts/tree/main/ofl/iansui

The WenKai WOFF2 file is a full-font conversion of the official TTF file,
without removing characters or changing outlines. Each font's SIL Open Font
License is included alongside the font file. English uses Arial / Helvetica Neue
for readable body text and Georgia for magazine accents. The unused Great Vibes
asset and its license are retained, but are no longer loaded by the invitation.
