# Invitation fonts

The invitation serves these Google Fonts locally so it does not depend on a
third-party font request inside LINE's browser.

- **LXGW WenKai TC Regular** — Traditional Chinese handwriting, from
  https://github.com/google/fonts/tree/main/ofl/lxgwwenkaitc
- **Great Vibes Regular** — Latin calligraphy, from
  https://github.com/google/fonts/tree/main/ofl/greatvibes
- **Iansui Regular** — retained as a fallback for missing characters, from
  https://github.com/google/fonts/tree/main/ofl/iansui

The WenKai and Great Vibes WOFF2 files are full-font conversions of the official
TTF files, without removing characters or changing outlines. Each font's SIL
Open Font License is included alongside the font file. English uses Great Vibes
as the approved substitute for Adelio Darmanto.
