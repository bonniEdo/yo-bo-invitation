# Wedding typography

Autery (user supplied) is used for English letters and ampersands; its included license permits personal and commercial use. It has no numeral glyphs.

Star Panda Kids Beta 2.1 is used for Chinese and numerals. The CSS references the author's original immutable file URL instead of redistributing or modifying the font. The author source matches the user-uploaded font SHA-256 554ead9138199803806a82b2918da1ca55e6789a05c2c236772a6bf6ded51040.

Author/source: https://github.com/cyberinkflow/StarPandaKidsFonts

The existing WenKai face is the fallback if the external font is unavailable or a glyph is missing. Font display uses swap so content stays readable while loading.
